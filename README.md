# COO Command Center — demo

A 3:20 narrated walkthrough of the COO Command Center: an executive dashboard
that aggregates live status from the systems teams already work in — Aha,
Jira, Salesforce, Oracle, Tableau — onto one page, grouped by portfolio.

**[▶ coo-command-center-demo.mp4](coo-command-center-demo.mp4)**

What the walkthrough shows:

- Six business units, five source systems, one page — nothing recalculated
  here; every number is published by the team that owns it
- Building a brand-new card from a plain CSV in under five minutes —
  measured, not a guess — with agents writing the integration code
- Access control: editing sits behind a one-time code mailed to the owner;
  to everyone else the dashboard is read-only
- Connector debug mode: when a source misbehaves, the page names the file,
  the exact edit, and the command that proves the fix worked — written so
  an agent can run it

All data shown is synthetic demo data.
